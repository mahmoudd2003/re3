# WordPress Article Updater - AI Micro Edit

هذا المشروع يحدث مقالات ووردبريس تلقائيًا عبر GitHub Actions، ويستخدم OpenAI لتعديل فقرة واحدة تعديلًا بسيطًا جدًا أقل من 3%.

## Secrets المطلوبة في GitHub

- SITE_URL
- WP_USERNAME
- WP_APP_PASSWORD
- OPENAI_API_KEY
